# 模型推理的基本机制
- 自回归模型：预测文本是逐个Token生成的，经过计算logits分数然后进行softmax完成，最后进行decoding选择输出token
- 贪婪解码(greedy decoding)：在每一个时间步上面都选择预测概率最高的token，问题点在与贪婪解码只关心局部最优，可能会放弃一个概率较低但是潜力大的token
- 束搜索(Beam Search)：束搜索引入了束宽，在么一个生成的步骤中同时维护K个概率最高的候选序列，当K=1的时候便变为了贪婪解码，问题为在开放式生成中，这会导致输出平淡，通用，重复的东西，人类的语言不是总是最求概率最高
- 纯采样(Vanilla)：根据softmax直接输出整个词表上的原始概率分布，会导致内容严重失真，因为噪音的比例哪怕很小在大量低概率词汇中也会变得很大
- top-k：使用硬截断概率最高的前k个token然后归一化后再采集，这样能消除尾部噪音但是当预测目标极度明确时，例如某个词概率很大的时候，top-k会截断很慢因为在强行把尾部没有意义的数字凑进来
- top-p：不使用固定数量，而是截取累计概率和达到p
- temperature sampling：给一个超参数 $\tau$，如果 $\tau$ 大于1变使得输出有创意和随机，如果小于1 变集中在头部

# deepseek的奖励机制
- 放弃了过程的奖励模型，而是变为结果驱动的奖励
1. 准确率奖励，使用二值化(非对即错)
2. 格式奖励，最终答案在规范格式内边给与微小奖励
3. 过程奖励容易出现奖励黑客(模型转空子)
- 模型涌现出了推理的能力，例如能够自我校验，自己自动重新进行演算，可以反思和回潮，当发现走不通的时候可以自己主动换新方法，有思考时间越长，准确率越高的规律
- 问题点：可读性较差，因为逻辑轨道混乱，人类难以阅读，在单个回答中会频繁使用多国的语言
- RL可以诱导推理，不需要大量的监督数据才能学会思维链，可以使用RL拓展上限，SFT(监督学习)提高可读性和可靠性

# Cot-Decoding
- 挑选候选人(用top-k/top-p)然后各自拓展，最后选择最合适的，注意：最后的挑选是看思考过程是否显著提高了最终答案的置信度
- 预训练模型内部天生具备推理路径，只是默认的贪婪解码覆盖了
- 希望能够挖掘预训练模型自己的推理能力
- cot的本质就是把居于的关系串联起来，推导出训练中没有出现过的全局结论
- 有些模型在强化学习中的能力剧增，但是有些却会陷入瓶颈，这取决于基座的模型能不能有四个认知行为，包括验证(推进下一步前会检测前面)，回溯(识别错误的路径)，子目标设定(把复杂问题变为独立子问题)，逆向链表(从目标反推)
- Cot会隐瞒自己利用了捷径的事实，而且这种隐瞒人类很难识别到
- 有时候直觉可能会比思考过后回答给出更差的结果
