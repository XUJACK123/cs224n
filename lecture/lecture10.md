# Adapter 模块
- 用于预训练语言模型的高效参数微调的方法，核心理念为冻结原始预训练模型参数的前提下加入小型的可训练的模块，使得只用更新很小的参数量
- 基于adapter的微调能够比全量微调少两个数量级的可训练参数，达到和全局微调一样的准确率
- 除了adapter之外也有知识蒸馏的方法，通过Teacher Model指导Student Model，将大模型的推理迁移给小模型

# 问答系统和RAG
## 问答系统
- 目标：让计算机理解自然语言的提问然后返回答案，也就是说要直接给出精准的答案片段
- 文本阅读理解：经典的抽取式问答，给系统阅读指定的上下文段落，从原文中提取出回答的片段，例如：文章是小明今天中午十二点在学校食堂吃了一碗牛肉面，问题为小明中午吃了什么？AI必须精准输出“牛肉面”这三个字，而不是把“小明/中午/食堂”这些关键词甩给你，也不能把整句话复制给你。
- 结合图像和文本进行跨模态的推理，例如回答图中有多少个人
- 传统的方法：枚举所有可能的答案，例如把所有的token都列出来为答案，然后训练多分类逻辑回归进行打分和排序，神经网络方法：将任务变为边界预测的问题(改为预测答案文本在背景文本中的起始和结束的位置)

## RAG
- 新增或修改知识只需要更新外部的文档，不需要重新训练或者是微调
- 模型的回答附带引用的指针，方便用户追溯并且验证信息来源
### Retriever-reader：
- 可以简单理解为retriever是从几百万篇文章里快速把相关的几本(Top-K 段落)找出来，reader再把找出来的书提取或生成答案
1. 检索器(Retriever)：输入包含大量文档的集合与问题，快速筛选出top-k个候选段落
2. 阅读器(Reader)：通过神经网络阅读理解，从候选的段落中提取出最后的答案
*** 和端到端(encoder-decoder)模型的区别，Encoder-Decoder可以在计算出loss后一路反向传播回encoder，所有的参数同时更新，一起训练，但是retriver-reader是存在不可导断层的，没有神经网络参数，也无法反向传播，同时，Retriever-Reader面对的是海量数据库，而不是单纯的上下文 ***

### Retricver
- 表达能力和计算效率的博弈：
1. 基于表示的相似度：DSSM，双塔向量，Query和Document独立编码为单向量，通过点积/余弦匹配，速度最快，把文本压缩为一个单个固定维度的向量
2. 全注意力交叉编码：将Query和Document拼接以后共同输入深度transformer网络，精度高但是计算极慢，每次查询都要对候选的文档运行一次完整的模型，每个词都互相匹配
3. 延迟交互：先把每一个词压缩为各自的向量，然后拿问题的向量去和文中的向量逐一比对，把得分最高的相关的问题向量相加得出最后的相关度得分

# Language Agents
- 核心痛点：长文本位置偏置，检索上下文过载以及引用幻觉
1. 有迷失在中部的现象，当包含答案的文档在头部和尾部的时候信息的关注度最高，在中部的时候信息的提取率最低
2. 喂入10到20分文档后变回迅速到达了瓶颈，继续喂入文档反而会因为上下文的噪音增加而干扰了模型的判断
3. 引用幻觉：经常出现引用的连接无法支持前文的段落
- 解决方法：
1. 针对引用幻觉，可以使用一致性检验(利用QA/NLI模型来检测生成文本与检索的证据是否一样)，自动修正，如果发现不一样或者是缺乏证据便使用修改模型重写文本

## 从文本的预测到闭环交互
- 建立智能体根据环境的观察做出决策，执行动作，动作改变环境状态后再产生新的观察

### plannning and reasoning
- 负责将复杂任务拆解为可执行的子目标
- 智能体的推理是担当了内部动作，通过连接外部的环境观察和外部动作
1. 思维链：通过引导模型一步一步输出中间思考的过程以求解问题，问题在于缺乏与外部环境的实时交互
2. 推理与动作融合：采用思考->工具调用->获取环境反馈的交替迭代循环，能够将幻觉率降到0左右，在复杂问题超过单纯的act/cot范式
3. reflexion架构：引用Actor，Evaluator和Self-Reflection模块组成的反馈闭环，当失败的时候evaluator会提供评估信号，能够持续压低低效规划和幻觉错误率

### memory
- 必须引入独立的存储和检索机制
1. episodic memory：存储具体的历史经验和带有时间戳的事件流，$$\text{Retrieval Score} = \text{Recency} \times \text{Importance} \times \text{Relevance}$$，recency为时效性，随着时间不断衰减，Importance为重要性，由LLM对事件进行评分，relevance为相关性，基于Query和事件文本的向量相似度
2. semantic memory：存储从事件中抽象出来的概念，知识和结论，LLM会周期性的对底层原始的事件进行反思和归纳，提炼出高阶的认知
3. procedural memory：存储可重复执行的动作和技能代码

### 工具使用，让LLM学会使用外部的工具和API
1. toolkenGPT：将工具显式映射为词表token，每一个外部工具都表示为一个特定的token，在embedding中学习其向量的表示，也可以从推理模式变为工具模式
2. toolformer：一种自监督的训练方法，让模型自己决定何时调用哪个API，传用什么参数，不用人工标记
3. Gorilla：自动抓取大量真实的API文档构成训练集，结合检索增强，让调用的每一个函数和参数都能准确
