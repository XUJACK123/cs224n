# 提示词范式与微调
## prompt
- 在不改变模型的参数的情况下通过输入指令/上下文/实例来引导模型生成指定东西，通过调整输入来改变token的输出
- 直接的提问很难面对复杂的问题，难以一步得到答案
- 在输入的时候明显的给出逻辑示范，让模型更好的去给出输出
### chain-of-thought prompting(Few-Shot CoT)
- 模型回答新问题的时候会示例中包含完整的解题推理过程然后让模型去计算
### Zero-Shot CoT
- 直接提问后附带类似于"Let's think step by step."的语句，然后模型就会自己拆解问题然后给出答案
- 结果略逊于Few-Shot-CoT
- 不同的引导词给出的效果不一样，例如"Let's think step by step" 达到78.7%，但是"The answer is after the proof." 只有45.7%

# PEFT
- 全参数微调：训练显存的开销很大，每个任务都要保存一份完成的权重(为了避免遗忘前面的能力，只能让不同的任务各自形成自己的完整权重，例如写代码的能力，和医疗问题的能力都需要有自己的权重)
- PEFT：冻结预训练模型绝大部分参数，只更新一部分参数
- 参数视角：直接用于模型的权重矩阵，只需要修改一部分参数/矩阵然后再加回主权重即可
- 输入视角：不改变模型内部，在输入/隐藏层直接拼接可学的向量
- 函数视角：在关键的计算节点加入小的结构
## Pruning
- 因为有些参数在神经网络中的重要度不高，因此可以直接丢弃
1. 移除绝对值最小的一部分权重
2. 对于剩下的权重进行二次的训练
### Diff Pruning
- 只会更新某些特定的参数，因为这些参数是属于特定的任务的
### The Lottery Ticket Hypothesis
- 把某些子网络给提取出来，恢复到初始化状态然后重新训练

# LoRA
- 用两个小矩阵相乘来代替原本要更新的矩阵的变换量，例如矩阵A把高维度变为小维度，B把小维度变为高维度(只在训练阶段，但是小矩阵只包含了特定任务，而大矩阵有全部任务，满秩和低秩的区别)
- 这两个小矩阵所需要训练的参数比大矩阵要小，因此能够训练更快，内存消耗更小

# Prompt-Tuning
- 不再由人类编写文本而是在输入的Embedding层前加上一串可训练的连续向量使得输出结果更好，类似于prompt但是不是由人类写的
